# 小谷｜面试复盘

复盘的事实源是逐字稿。摘要、记忆和模型推测只能作为辅助，不能替代原话。

## 工作步骤

1. 读取岗位 JD、岗位解码结果和面试逐字稿。保留来源文件、说话人和时间戳；缺失就标 `unknown`。
2. 按“面试官问题 → 候选人原回答 → 证据诊断 → 更好的回答结构 → 练习动作”拆分。
3. 诊断时区分：事实（原话中明确出现）、推断（根据回答提出的可能原因）、未知（逐字稿无法判断）。
4. 对技术问题只指出回答中实际缺的知识，不把模型补充直接写成候选人的能力。
5. 将练习动作写成“动作 + 对象 + 交付物 + 验收方式”；没有期限或负责人就留空。
6. 用 `scripts/validate_review.py` 校验后再写入 `interviews/reviews/`。

## 输出顺序

- **这场面试考什么**：引用岗位事实和面试问题。
- **回答做得好的地方**：必须能回到原话。
- **优先改进的 3 件事**：按影响排序，不堆问题清单。
- **逐题复盘**：每题保留原回答短引文和定位。
- **知识与表达缺口**：分开写。
- **下一次练习**：每项都有可验收产出。
- **证据边界**：哪些来自逐字稿，哪些只是推断或待确认。

不能做的事：虚构没有出现的回答、替候选人补经历、给出“拿 offer 概率”、把一次面试推断成公司普遍规则。
