# 小谷话术层

本文件规定写进 `answer`、`evidence`、`unknown`、`next_action` 的措辞，不新增输出格式。格式与校验见 [output-contract.md](output-contract.md)。可回归样例在 `examples/algorithm-engineer-mock/expected/`。

设计依据（docs/research/job-seeker-core-questions-2026-10-03.md）：70.2% 受访应届生认为岗位实际内容描述不清，68.4% 认为待遇含糊，62.7% 认为晋升画饼。所以话术的第一职责是把“招聘方写了什么、没写什么、别人怎么说”分开，而不是给出好坏结论。

## 通用规则

1. `answer` 第一句说这个岗位用大白话在干什么；第二句说招聘说明写清了什么、没写什么。
2. 有从业者说法时，`answer` 只用一句话概括最重要的发现，优先说与招聘说明冲突的那条；帖子细节放 `evidence`。
3. 专业词第一次出现就解释，例如“召回排序（决定给用户推什么、按什么顺序推）”。
4. `next_action` 只给一个动作，优先是“问招聘方的一句话”，问题要能直接复制发送。
5. 冲突不判对错：写成“X 说……，Y 说……，需要当面问清”。只有明确说的是这家公司的帖子（`same_company`）才能叫“对不上 / 冲突”；同类岗位帖子只能说“同类岗位有人反映……，这家是否如此需要当面问清”。

禁用说法：业内普遍、大家都说、据可靠消息、这家公司一定、基本可以确定、肯定会加班；以及任何录用概率、薪资预测。

## 三层来源的固定说法

| 来源 | evidence 标签（渲染器自动加） | 措辞要求 |
|---|---|---|
| JD 原文 | JD 原文 | 用引号原句，不改写 |
| 本地词典 / 职业库 | 参考资料 | 写“同类岗位一般情况”“在招聘话术里通常”，不写成这家公司的事实 |
| 牛客、脉脉帖子 | 从业者分享（未核实），并自动附来源、日期、链接 | 复述要点，原文引用单处不超过 30 字 |

## 从业者说法：各状态话术

| 状态 | answer 追加一句 | unknown 追加 |
|---|---|---|
| 这家公司的帖子与 JD 冲突 | 有自称这家公司 X 组在职的人说……，和招聘说明的“……”对不上，需要当面问清。 | “这个团队是否……（这家公司从业者的说法与招聘说明冲突）” |
| 同类岗位帖子提到 JD 未说清的风险 | 同类岗位有人反映……；这家是否如此，招聘说明的“……”回答不了，需要当面问清。 | “这家公司实际是否……（同类岗位有人反映，这家未知）” |
| 同类岗位帖子、无风险分歧 | 同类岗位的从业者分享主要补充了……。 | — |
| 只有两年前的帖子 | 唯一找到的从业者分享是 YYYY 年的，只能当作当时的情况参考。 | 近一年从业者的实际说法（只找到较早的分享） |
| 只有一条匿名说法 | 只找到一条匿名说法，信息太少，不能当成这个岗位的实际情况。 | 相关话题（只有一条无法核实的匿名说法） |
| 只有相邻团队的帖子 | 找到的分享来自 X 团队，不是 Y 团队，只能间接参考。 | Y 团队从业者的实际说法（目前只有相邻团队的分享） |
| 没找到 | 不追加 | 见决策点 B |
| 某来源被禁止读取 | 不追加 | “脉脉上的说法：这个网站不允许当前工具读取，这次只参考了……”；不出现 robots、User-Agent 等词 |
| 宿主没有联网工具 | 不追加 | “从业者的实际说法：当前环境不能联网，以上判断只基于招聘说明和资料库” |

## 待用户选择的两个决策点

两处都已在 `examples/algorithm-engineer-mock/expected/` 生成可对比的完整输出。选定前默认使用 A2 和 B1。

**决策点 A：命中帖子时怎么呈现**
- A1 标签式（`full__A1_label.md`）：只靠“从业者分享（未核实）”标签提示，正文直接复述。最短，但新手要自己判断作者身份。
- A2 适用范围式（`full__A2_scope.md`）：每条句首写作者身份和适用范围，例如“（匿名，自称某中厂推荐组在职；同类岗位，不是这家公司）”。较长，但不用用户自己判断能信几分。
- A3 汇总式（`full__A3_summary.md`）：结论里先报“找到 3 条，2 条说……1 条说……”，依据里正文直接复述。能看出多数和少数，但条数少时容易被读成统计结论。

**决策点 B：没找到从业者分享时怎么说**
- B1 只在仍需确认里写一行（`no_results__B1_unknown.md`）。下一步仍然是问招聘方工作占比。
- B2 同 B1，并把下一步改为“请招聘方安排和团队工程师聊 10 分钟”（`no_results__B2_action.md`）。获取信息更直接，但对新手开口门槛更高。

已排除：没找到时不提。不提的话，新手会以为小谷查过了而且没有问题。
