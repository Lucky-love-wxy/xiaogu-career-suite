# JD 解码输出契约

报告至少包含：

```yaml
source:
explicit_claims:
  - field:
    value:
    source_quote:
jargon:
  - term:
    source_quote:
    literal:
    blunt:
    risk_hypothesis:
    worst_case:
    red_flags: []
    verification:
    good_answer:
work_model:
  tasks:
  deliverables:
  evaluator:
  metrics:
  resources:
  decision_rights:
missing_fields:
conflicts:
priority_questions: [] # 最多 3 个
```

事实、推断和未知必须分开。禁止输出“坏公司概率”“面试通过概率”“一定加班”等没有校准依据的数字或结论。
