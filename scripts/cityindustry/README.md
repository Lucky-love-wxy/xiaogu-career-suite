# 城市产业组成调研 — 采集规范

本目录存放「城市产业组成」调研的采集规范与脚本。产出物：

- `data/careerdb/city_industry.csv` — 主数据表，一行一城
- `docs/research/city-industry-2026-10.md` — 报告
- `evidence/city-industry-2026-10/` — 原始证据（.gitignore 已排除）

## 城市范围（19 城）

- 一线 4：北京、上海、广州、深圳
- 新一线 15（《2025新一线城市魅力排行榜》，第一财经·新一线城市研究所，2025-05-28 发布）：
  成都、杭州、重庆、武汉、苏州、西安、南京、长沙、郑州、天津、合肥、青岛、东莞、宁波、佛山

## 每城要回答的问题

1. 三次产业结构：一、二、三产增加值占 GDP 比重，最新一年（市统计局国民经济和社会发展统计公报）
2. 服务业大类：信息传输软件、批零（网络零售额单列）、金融、租赁商务、科研技术
3. 工业重点行业：公报列出的规上工业重点行业/产业链，照原文名称
4. 政府主导/重点产业：最新市政府工作报告或「十四五」规划纲要原文
5. 就业结构：按行业城镇单位就业人员数（统计年鉴），只记能找到的年份

## 证据标准（硬约束）

- 一级来源只认：市统计局公报/年鉴、市政府工作报告、市级规划纲要原文
- 媒体转述为二级，必须标等级，不能单独当结论
- 每份原文存 evidence 目录，记 SHA256
- 查不到写「未找到」，不用常识补；口径不一致并列写，不替小谷裁决
- 遵守 robots；单站请求间隔 ≥ 3 秒；遇验证码/风控立即停；不用登录态、不付费

## 字段 schema

主表 `city_industry.csv` 列：

```
城市,城市级别,三次产业结构年份,一产占比%,二产占比%,三产占比%,服务业_信息软件,服务业_批零,服务业_网络零售额,服务业_金融,服务业_租赁商务,服务业_科研技术,工业重点行业,政府主导重点产业,就业结构年份,就业结构说明,来源编号
```

来源表 `city_industry_sources.csv` 列：

```
来源编号,城市,来源类型,url,标题,发布方,发布日期,访问日期,文件路径,SHA256,原文短摘,证据等级,页码或条目号
```

「来源编号」用 `C{城市拼音首字母}{序号}`，如杭州 `CHZ01`。
