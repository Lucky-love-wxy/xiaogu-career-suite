## 背景

小谷要把「从业者真实说法」设为岗位理解的默认步骤（不再等用户说「去脉脉看看」）。已核实（2026-10-03，Claude）：
- 脉脉 robots.txt 对 ChatGPT-User、豆包、Kimi、混元、通义、DeepSeek 等只放行公开详情页（`/community/gossip-detail/`、`/article/detail`、`/company`、`/seo/`、`/geo/...`）；对 Claude-User / ClaudeBot 和默认 `*` 全站 Disallow。社区首页 307、站内搜索 302 跳登录。
- 牛客 robots.txt：`User-agent: *` 只禁 `/search`、`/nccommon`、`/ab/ab-test-flow`，提供多个 sitemap。**未测过任何内容页。**

## 必须回答的问题

### Q1 同类产品怎么获取「岗位实际做什么」（回填设计文档 1.3）
- 范围：国内求职 AI / 求职工具至少 5 个（例：效招 Joblytic、牛客 AI 功能、BOSS 直聘内置 AI、职徒简历、看准网），海外至少 2 个（例：Glassdoor、Teal、Jobscan 任选）。
- 每个产品回答：信息来源是什么（自有 UGC / 抓取第三方 / 模型常识 / 无）；是否标注来源与日期；如何区分「招聘方说的」与「员工说的」；有无公开的失败/降级表现。
- 只收公开可核实的信息，产品宣传话术要标「厂商自述」。

### Q2 牛客可访问性
- 讨论帖、面经帖详情页：未登录能否拿到正文？是服务端 HTML 还是前端渲染（curl 拿到的 HTML 里有没有正文）？
- 用户协议 / 服务条款中关于自动化访问、AI 抓取、转载引用的原文条款（robots.txt 不等于条款）。
- 帖子日期、作者身份标签（在职/校招/实习）是否在页面可见。

### Q3 发现路径
- 两站站内搜索都不可用，只能经外部搜索引擎发现帖子。实测百度、必应、搜狗、Google 对 `site:nowcoder.com 算法工程师 面经`、`site:maimai.cn 算法工程师` 的返回：条数、前 10 条是否为详情页、是否新近。
- 牛客、脉脉 sitemap 能否作为发现入口（体量、更新频率、是否含岗位关键词）。

### Q4 抓取身份（2026-10-04 改写）
- 产品已改为自建 Web Agent，抓取由小谷服务器以自有 User-Agent（拟为 `XiaoguBot/0.1 (+联系方式)`）发出，WorkBuddy 的身份不再相关。
- 请核实：牛客、看准网、知乎专栏、应届生求职网等候选来源的 robots.txt 对未列名代理（`*`）是否放行详情页；逐站列出放行路径。
- 脉脉对 `*` 全站 Disallow（2026-10-03 实测），不在小谷可用来源内，无需再测；不得建议冒用放行名单里的身份。

### Q5 算法工程师真实数据（替换模拟数据）
- 公开 JD 5 份（不同公司规模：大厂、中厂、创业公司），保存全文与链接。
- 牛客 / 脉脉公开详情页从业者帖子 10 条以内，覆盖：日常工作占比、加班、指标、成长；每条记录链接、发帖日期、作者身份标签、可复述要点（不整段复制）。
- 格式对齐 `examples/algorithm-engineer-mock/live_sources.json`，字段一致，以便直接替换做回归。

### Q6 搜索 API 选型（2026-10-04 新增）
- 小谷需要一个搜索 API 做“发现帖子”（站内搜索都不可用）。至少比较 4 个候选（例：博查 Bocha、百度千帆 AI 搜索、Tavily、SerpAPI 的百度/必应引擎、必应搜索 API 后继产品），记录：中文结果质量（用 `site:nowcoder.com 推荐算法 面经` 等 5 条固定查询实测前 10 条）、是否支持 site 限定、返回是否含摘要/日期、价格与免费额度、限流、服务条款是否允许 AI 产品或商用、是否需要国内主体。
- 只用官方文档与实测；厂商宣传与实测分开写。

## 证据标准

1. 一手优先：产品官网/官方文档/原帖页面 > 媒体原创报道 > 转载。
2. 每条结论附 URL + 访问日期；截图或 curl 输出存 evidence 目录。
3. 查不到写「未找到」，不用常识补齐；厂商自述与实测分开写。
4. 遵守 robots 与条款：被禁止的路径不访问；不用登录态、不复制 Cookie、不绕验证码；单站请求间隔 ≥ 3 秒。
5. 帖子内容只做要点复述，引用原文单处不超过 30 字。
