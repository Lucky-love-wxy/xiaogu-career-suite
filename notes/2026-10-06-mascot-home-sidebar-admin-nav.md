# 吉祥物主页、对话页侧栏、后台导航与动效

## 元数据

- 日期：2026-10-06
- 任务名：主页改为展示吉祥物小谷并加简单互动；对话页侧栏以历史对话为中心、功能收起；用户中心缩小为可点击菜单；后台加飞书式左侧导航；全站加过渡动效
- 所属项目：xiaogu-launch（小谷上线版）
- 触发类型：设计
- 关联 Principle：暂停中，不挂编号

## 1. 市场调研结果

来源说明：以下为对各产品公开界面的观察，基于截至 2026 年的常见版本，没有逐一截图存证；具体细节以产品现版本为准（推测成分已标出）。

### 1.1 对话类产品的侧栏

| 产品 | 侧栏视觉中心 | 功能入口放哪 | 用户中心 |
| --- | --- | --- | --- |
| ChatGPT | 历史对话列表，按时间分组 | 顶部只有新对话、搜索；GPTs / 项目各占一行；工具（上传、联网等）收在输入框的「+」里 | 左下角头像一行，点开弹出菜单（设置、升级、退出） |
| Claude | 历史对话（Recents） | 新对话、项目各一行 | 左下角头像，点开菜单 |
| Kimi / 豆包 | 历史对话 | 少量常用入口；更多功能放在输入框旁或首页 | 左下角头像，点开菜单（推测：各版本位置有差异） |

共同做法：侧栏 80% 以上的高度给历史对话；功能入口最多两三行，其余收进输入框的「+」或首页建议；用户中心是一行头像，点击后弹出小菜单，侧栏收起时只剩头像。

### 1.2 管理后台的左侧导航

| 产品 | 结构 |
| --- | --- |
| 飞书管理后台 | 左侧固定导航，按业务分组（如组织架构、工作台、安全、计费），一级项带图标，可展开二级；右侧为当前页内容；导航可收起到图标栏 |
| 阿里云 / 腾讯云控制台 | 同样是左侧分组导航 + 右侧内容，顶栏放全局操作 |

共同做法：一屏只看一类内容，不把所有板块堆在一页长滚动里；当前项高亮；全局危险操作（本项目的「全局停止」）放在顶栏，任何页都能点到。

### 1.3 吉祥物主页与互动

| 产品 / 做法 | 互动 |
| --- | --- |
| Duolingo 官网 | 吉祥物 Duo 是主视觉，有循环小动作、点击 / 悬停反馈 |
| GitHub 登录页（Octocat）、各类开源项目落地页 | 眼睛跟随鼠标、自动眨眼——实现成本低、常见 |
| Apple / Linear 等产品页 | 滚动到位时内容淡入上移；主视觉随鼠标轻微视差、倾斜 |

共同做法：只做三到四种轻互动（视线跟随、眨眼、点击换表情、滚动淡入），动作要小、可被系统「减少动态效果」设置关闭。

## 2. 我要解决的问题

1. 主页没有品牌形象。用户已设计吉祥物，主页要以它为主视觉，并有轻互动；对话页不放吉祥物，避免干扰。
2. 对话页侧栏被五个功能入口占了大半，历史对话被挤到下面。改为历史为中心，功能收进输入框「+」菜单和首页建议。
3. 用户中心不能点、不能收。改为一行头像，点开弹出菜单（额度、配色、协议、退出）；侧栏收起时只剩头像。
4. 后台是一页长滚动，找板块要翻。改为飞书式左侧分组导航，一次只显示一组内容，顶栏保留全局停止。
5. 交互生硬。补齐过渡：消息出现、侧栏收起、菜单弹出、页面切换、按钮按下；尊重「减少动态效果」。

素材限制：只有一张设定拼图（1536×1024）。主页的 3D 主视觉从拼图裁出（450×683，高清屏会略糊）；可互动的小谷用 SVG 按设定图正面造型重画（能做眼睛跟随、眨眼、换表情）。用户提供透明底高清原图后替换。

## 3. 适用的设计规范

- 前端风格：黑底白线为默认（用户 2026-10-06 指定），主页吉祥物区用柔和的灰白光斑托住黑色角色，避免黑融进黑。
- 按钮一律圆角矩形；纯文字按钮悬停出圆角底色（用户 2026-10-06 指定）。
- AI 协作 SOP：关键决策点不直接采纳 agent 建议——本文第 2 节的信息架构调整都来自用户原话。
- 外科手术式改动：对话页的回答渲染、流式接收、埋点逻辑不动，只改侧栏结构、用户菜单、输入框「+」和动效。
- 中国大陆可用：不引外部字体和外部动画库，动效全部用 CSS 和少量原生 JS。
