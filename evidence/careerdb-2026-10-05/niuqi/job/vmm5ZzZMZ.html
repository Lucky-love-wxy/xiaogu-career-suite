    公司简介


    世界图书出版上海有限公司成立于1993年3月，是世界图书出版有限公司在国内的重要分支机构之一。公司始终秉承把世界介绍给中国，把中国介绍给世界的办社宗旨，以科教兴国、书兴科教、服务科研、服务高校为使命，坚持为我国科教事业发展贡献力量。 

    自成立以来，世图上海公司逐步形成了以科技、医学、教育等专业出版为核心，实用外语、生活科技等大众出版为辅助的产品体系。公司早在20世纪80年代便引进出版《新概念英语》，该书风靡全国，成为非官方英语学习的经典之作，销量逾百万套，是中国出版业引进版权成功的标志性案例。 

    多年来，公司持续引进国外高水平科技医学类图书与期刊，累计购权重印对我国科研教学具有重要影响的科技期刊逾千种。同时，积极推动国内优质图书的出版与走出去，多项图书荣获国家级、省部级重要奖项，如《当代药用植物典》获中国出版政府奖，《环境与儿童健康》获引进版优秀图书奖，多部作品入选国家、集团十三五十四五重点规划项目，持续为我国学术出版与知识传播作出积极贡献。




    招聘岗位


    01

    医学出版中心负责人（1人）

    岗位职责： 

    1. 贯彻执行公司经营宗旨和出书计划，把握医学类图书出版导向和方向，做好医学类选题的总策划，形成有规模有发展的产品线。

    2. 根据公司发展战略和目标，制订经营方针、经营计划，并组织落实和监督实施，完成整体任务指标。

    3. 对出版图书导向与质量负责。

    4. 监督出版物的生产，确保图书质量的情况下，严格控制生产期限和预算。

    5. 负责编辑人员的业务培训工作、编辑队伍建设工作。

    6. 完成公司布置的其他工作。


    任职条件：

    1.医学类等相关专业本科及以上学历，有10年以上的出版工作经验。

    2. 有专业医学背景和扎实的专业基础以及不断更新知识的学习能力，熟悉出版工作。

    3. 具有较强的组织管理能力和选题策划能力，能够迅速根据市场需求进行选题策划，组织合适作者，出版双效图书。

    4. 符合世界图书出版上海有限公司中层干部履职条件。

    02

    医学编辑（2-3人）

    岗位职责：

    1.根据部门选题规划，配合部门领导做好部门医学类图书的选题策划、组稿、编辑加工等编辑全流程出版工作。

    2.能独立对负责的相关图书做好市场调研及文字宣传工作。

    3.协同出版部门和美术编辑做好图书的装帧、设计工作。

    4.协同发行、营销部门做好相关图书的营销策划宣传工作。


    任职资格：

    1.全日制本科及以上学历。

    2.所学专业（方向）与医学专业相关。

    3.具有较强的文字编辑能力、审美能力。

    4.具有较强的岗位责任心，职业道德和素养，能够承担一定的工作压力，具有团队合作精神。

    5.工作主动性较强，有较强的责任意识和创新能力。

    6.有相关医学图书编辑工作经验、党员优先。

    03

    综合编辑（2-3人）

    岗位职责：

    1.根据部门选题规划，配合部门领导做好部门综合类图书的选题策划、组稿、编辑加工等编辑全流程出版工作。

    2.能独立对负责的相关图书做好市场调研及文字宣传工作。

    3.协同出版部门和美术编辑做好图书的装帧、设计工作。

    4.协同发行、营销部门做好相关图书的营销策划宣传工作。


    任职资格：

    1.全日制本科及以上学历。

    2.所学专业（方向）：社科、理工科相关专业。

    3.具有较强的文字编辑能力、审美能力。

    4.具有较强的岗位责任心，职业道德和素养，能够承担一定的工作压力，具有团队合作精神。

    5.工作主动性较强，有较强的责任意识和创新能力。

    6.有相关理工科专业图书编辑工作经验、党员优先。

    04

    发行部负责人（1人）

    岗位职责：

    1.全面负责出版社图书产品的市场发行、销售渠道管理与团队建设工作，确保发行任务和回款目标的完成，提升出版社品牌市场占有率和影响力。

    2.根据出版社整体战略和年度经营目标，制定并实施年度、季度、月度发行战略、销售计划和预算。

    3.深入分析图书市场趋势、竞争对手动态和客户需求，为产品定价、首印量决策及营销策略提供数据支持。

    4.负责全面规划和管理发行渠道，建立并维护与关键渠道客户、经销商的长期稳定战略合作关系。

    5.组织、指导并监督团队进行日常销售工作，并负责整个部门的应收账款管理，制定回款计划、监督催款工作，确保资金安全、及时回笼。

    6.建立和完善销售数据分析体系、监控各项关键指标，总结销售状况，发现问题并提出改进策略，为管理层决策提供依据。


    任职资格：

    1.全日制本科及以上学历。

    2.所学专业（方向）：出版、营销、管理等相关专业优先，5年以上出版发行工作经验，其中至少3年团队管理经验。

    3.精通出版发行全流程，熟悉各类图书销售渠道的运作模式和管理方法。

    4.具有较强的岗位责任心，职业道德和素养，具备一定的抗压能力，具有团队合作精神。

    5.具有较强的工作主动性，具有细致、耐心的工作态度，具备合规意识。

    05

    实习生

    岗位职责：

    1.协助完成书稿校对、内容整理、资料查阅与初审辅助工作。

    2. 参与图书选题调研、作者沟通及编辑流程相关事务。

    3. 协助图书订单处理、发货核对、库存登记、销售报表等数据整理。

    4. 对接渠道客户、书店及电商平台，做好日常沟通。

    5. 配合新媒体宣传，撰写书评、书单、推广文案。


    任职要求：

    1. 本科及以上，汉语言文学、外语、医学、理工相关专业优先。

    2. 工作认真负责，文字功底扎实，细心严谨，逻辑清晰，执行力强。

    3. 熟练使用Office办公软件，会基础数据统计。

    4. 熟悉小红书、知乎、抖音等新媒体平台，有内容写作能力优先。

    5. 在校学生，能稳定实习23个月，每周到岗3天及以上。

    06

    新媒体实习生

    岗位职责：

    1. 运营公众号、小红书、抖音、视频号等平台。

    2. 撰写推文、短视频脚本、活动文案，完成图文排版。

    3. 参与线上活动策划、数据复盘及粉丝互动。


    任职要求：

    1. 本科及以上，专业不限。

    2. 熟悉小红书、知乎、抖音等平台玩法，有运营或写作经验优先。

    3. 会基础排版/剪辑，网感好，创意强。

    4. 每周到岗3天及以上。
