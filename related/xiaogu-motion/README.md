# 小谷网页动效

基于用户提供的角色设定图制作的独立 Web 动效演示。SVG 是参考图的矢量演绎，不是原图的 3D 模型。

直接打开 `index.html`，或运行 `python3 -m http.server 8792 --bind 127.0.0.1 --directory /Users/lucky_wang/Documents/codex/xiaogu-motion`，访问 `http://127.0.0.1:8792/`。

无第三方依赖、无远程字体、无 API、无数据上传。支持电脑和手机布局、键盘操作、系统减少动态偏好。

## 修改地图

- 页面文案、角色 SVG 与控件：`index.html`
- 布局、配色、夜间场景和各部位关键帧：`style.css`
- 表情切换、目光跟随、招呼、暂停与速度：`motion.js`

## 行为

默认呼吸 / 眨眼 / 小芽摇摆。五种状态：待机、开心、思考、专注（笔记本）、加油（挥手）。点击角色或招呼按钮会临时打招呼，随后回到原状态；主动选择状态会取消临时招呼。速度依次切换 1× / 0.5× / 1.5×。系统减少动态时保留静态状态切换。
