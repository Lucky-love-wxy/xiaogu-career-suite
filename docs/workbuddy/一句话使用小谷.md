# 一句话使用小谷求职 Harness

## 你不需要记 Skill 名称

安装完成后，直接把你遇到的问题告诉小谷。小谷会自己判断应该看岗位、查黑话、改简历还是复盘面试。

例如直接说：

- “帮我看看算法工程师每天到底做什么。”
- “这份 JD 写得太绕了，翻译成人话。”
- “根据这个岗位和我的经历改简历。”
- “这是面试逐字稿，帮我找出最该改的三个问题。”
- “我现在下一步应该做什么？”

## 第一次安装

至少安装：

1. `xiaogu-career-master`：一句话总入口。
2. `xiaogu-career-suite`：岗位、JD、黑话和核实问题。

按需要安装：

- `xiaogu-resume`：岗位版简历。
- `xiaogu-interview-review`：面试逐字稿复盘。
- `xiaogu-boss-jobs`：读取 BOSS 直聘真实岗位，需要用户本人登录。

`xiaogu-jd-decoder` 和 `xiaogu-job-reality` 是旧版兼容 Skill，新用户不用专门学习。

## 第一句测试

打开新会话，只发送下面一句：

```text
小谷，帮我看看“推荐算法工程师，负责模型训练、实验评估和线上部署”这个岗位到底在做什么。
```

正确结果应先查数据库，并把 JD 明确事实、职业参考、推断和未知分开。用户不需要说“调用哪个 Skill”。

## 小谷怎样自动决定

| 你说什么 | 小谷自动做什么 |
|---|---|
| 找岗位 | 调用 BOSS 岗位读取 |
| 看岗位、JD 或黑话 | 调用岗位理解核心 |
| 改简历 | 先理解岗位，再调用简历 Skill |
| 复盘面试 | 先理解岗位，再调用面试复盘 Skill |
| 不知道下一步 | 读取当前岗位进度，给一个下一动作 |

如果缺少材料，小谷一次只会问当前最需要的一项。例如改简历但没有经历材料时，它只会先请你提供现有简历或真实经历。

## 使用脉脉等外部资料

如果希望小谷查看脉脉、其他职场社区或网页，需要额外安装并启用 `web-access`，同时保证 WorkBuddy 环境具有它能调用的联网或浏览器工具。

可以直接说：

```text
小谷，去脉脉看看从业者怎样描述这个岗位，把非官方个人经验和确定事实分开。
```

必须理解三个边界：

1. 安装 `web-access` 不等于已经登录脉脉，也不会自动获得 Cookie 或账号权限。
2. 2026-09-22 的未登录核验中，脉脉官网首页可以读取，社区入口跳转到登录页；站点行为可能变化，实际帖子能否读取仍取决于用户登录状态和当前工具能力。
3. 遇到登录墙、验证码、安全页或访问失败时，小谷应停止并说明失败。此时请提供具体链接、截图、合法导出或复制的帖子原文。

匿名帖子只能作为“有人这样经历过”的参考，不能直接写成公司事实或行业定论。
