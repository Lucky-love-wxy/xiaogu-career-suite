# 中国官方职业信息体系：设计与小谷复用判断

调研日期：2026-10-08。结论：中国官方分类与职业标准适合成为小谷的本土基础层，ESCO适合补充跨职业技能关系。两者不能替代中国招聘样本与真实从业经历。本报告完成体系与复用边界判断，未完成195节点逐条中国编码映射或全量标准采集。

## 1. 中国对应的体系

并非一份与ESCO同形态的数据包，而是几层相互衔接的资料：

| 层 | 官方资料 | 可供小谷使用的内容 | 边界 |
|---|---|---|---|
| 职业分类 | 职业分类大典、正式发布的新职业/新工种及调整信息 | 分类、职业编码、名称、定义、主要工作任务；数字/绿色职业标识 | 国家职业、工种、企业岗位不是同一粒度；新职业公示稿不能当已发布数据 |
| 工作能力 | 国家职业标准，包含技能类和专业技术类 | 等级、工作功能/领域、工作内容、技能/专业能力、相关知识、基本职业环境 | 规范性要求，不能直接代表实际岗位任务频率 |
| 培养评价 | 标准内的培训与考核要求、行业企业评价规范、专项职业能力考核规范 | 学习和能力评价框架 | 考试准入不等于企业招聘门槛；考核权重不等于工作时间比例 |
| 职业准入 | 职业资格目录及相应行业制度 | 判断特定职业的资格制度 | 职业标准存在不代表必须持证才能就业；须逐职业核实 |
| 市场描述 | 新职业就业景气报告、分地区企业薪酬调查等 | 带年份和地域的背景资料 | 不能覆盖所有职业，也不能把历史预测当2026年事实 |

2022年大典的发布基数为8大类、1639职业，包含97数字职业、134绿色职业。随后持续更新，1639不是本报告确认的2026年动态总量。[国家发改委发布信息](https://www.ndrc.gov.cn/fggz/jyysr/jysrsbxf/202210/t20221031_1340470_ext.html)

2023年规程新增专业技术类职业标准编制内容，并明确国家标准、行业企业评价规范、专项职业能力考核规范的衔接。不要把中国体系理解成只有初级工到高级技师。[正式印发通知](https://chinajob.mohrss.gov.cn/h5/c/2023-12-18/387993.shtml)

## 2. 国家如何组织职业调查与设计

分类更新的已核验流程是：申报者先做职业调查和职业分析 → 提交建议及实际工作资料 → 专家评审论证 → 征求主管部门及社会意见 → 人社部、市场监管总局、国家统计局联合审定发布。2025年通告允许新增职业、现有职业下的工种及职业信息调整；这解释了为什么企业新岗位不一定需要创造一个新国家职业。[2025年征集通告正文](https://chinajob.mohrss.gov.cn/h5/c/2025-09-05/448949.shtml)

2021年办事指南还明确必要时开展实地调研。这是调查与专家论证结合的生产机制；本轮没有取得支持“每个职业采用统一全国概率抽样、公开原始问卷与评分N”的证据，不能照搬O*NET调查统计的解释。[服务指南](https://chinajob.mohrss.gov.cn/c/2021-06-11/309623.shtml)

标准编制的实际案例是主管部门指导，专业机构组织，高校、企业和专家参与起草，另列审定人员，并将工作拆成有等级的能力与知识要求。该机制在人工智能工程技术人员标准的说明页可直接核验。对小谷的启示是：先定义职业边界和真实任务，再拆任务能力，最后做跨企业校验；不能先列抽象技能名再让模型补出岗位故事。

取证限制：正式2023年通知已读取，完整规程附件尚未取得。人社部PDF静态返回无正文；烟台转载附件超过工具内容上限；CDP创建页面报CDP_CONNECT_TIMEOUT，检查器最终proxy not ready。没有改浏览器设置、重启代理或占用屏幕。2023年7月征求意见稿只作线索，未把其中专家人数等细节作为正式规则。此缺口不影响已读正式职业标准的结构结论。

## 3. 与ESCO的区别及实际可复用量

ESCO公开提供3039职业、13939技能及其关系，支持CSV、ODS、RDF和API。它适合技能归一、跨职业匹配和数据交换。中国官方资料的优势是本土职业名称与具体工作能力标准；本轮未确认存在与ESCO等价的、全量可下载且明确许可的中国职业—技能图谱。[ESCO介绍](https://esco.ec.europa.eu/en/about-esco/what-esco)、[数据使用方式](https://esco.ec.europa.eu/en/use-esco)

| 问“多少”时的口径 | 本轮能确认的数字 | 不能推出的结论 |
|---|---|---|
| 分类基数 | 2022版1639职业 | 2026动态职业总数、195产品节点覆盖率 |
| 历史公开标准规模 | 2021年查询系统公布1109标准：898依据1999大典、211依据2015大典 | 1109份均为现行版本；1109/1639是标准覆盖率 |
| 本轮核验正文样例 | 人工智能工程技术人员59页、药物制剂工90页，共2份149页 | 已取得全量数据；全部页已逐条人工审核或完成结构化 |
| 产品中国映射 | 现有报告记录中国编码0/195；本轮未写入新的认可映射 | 中国资料没有对应职业；或预计能匹配某个百分比 |

[1109标准的官方历史公告](https://app.www.gov.cn/govdata/gov/202106/03/472048/article.html)说的是免费全文查询，不是当前全量CSV或商业镜像许可。技能人才评价工作网现有分类、标准和资格目录入口，但静态层跳回首页，动态系统未取到正文。[当前入口](https://www.osta.org.cn/index/)

人工智能2021标准含5个方向、3个等级，形成15个方向—等级组合，可用作能力分层；这不是15个独立国家职业。其表格将具体工作、专业能力和知识关联，适合映射算法类节点的候选任务与技能，不能未经范围核实整份挂到算法工程师上。[官方标准PDF](https://zsgx.mohrss.gov.cn/uploads/2024-10-24/%E4%BA%BA%E5%B7%A5%E6%99%BA%E8%83%BD%E5%B7%A5%E7%A8%8B%E6%8A%80%E6%9C%AF%E4%BA%BA%E5%91%98%E5%9B%BD%E5%AE%B6%E8%81%8C%E4%B8%9A%E6%8A%80%E6%9C%AF%E6%8A%80%E8%83%BD%E6%A0%87%E5%87%86.pdf)

药物制剂工标准编码6-12-03-00，有5个等级，工作表进一步列出制备操作及相关知识。它适合药品生产/制剂操作岗位的候选基础，不等于制剂研发、注册、医学事务或CRA都适用。正文依据2015大典和2018规程；本轮未确认它仍是该职业最新版本，入产品前需查替代标准并处理最新规程冲突。[官方标准PDF](https://chinajob.mohrss.gov.cn/upload/resources/jnbzpdf/4ccc6a76ab911e20ca5502.pdf)

## 4. 对现有12组岗位卡字段的复用地图

下表为来源能力分析，不是已填充字段统计。5组可打底、5组须补实证、2组由产品整理；不能把5/12称为42%的内容已完成。

| 组 | 岗位卡字段 | 复用方式 |
|---|---|---|
| 可打底1 | name / aliases | 官方名与编码可用；招聘别名另取JD，名称不能自动一一对应 |
| 可打底2 | plain_language | 用官方定义重写人话，保留适用范围 |
| 可打底3 | daily_work | 抽工作内容作为候选任务；常见、每天、时间占比另证 |
| 可打底4 | deliverables | 仅抽标准明确涉及的输出；推导输出需标推断 |
| 可打底5 | work_setting | 保留标准明确环境；出差、驻院、加班频率另证 |
| 须补实证1 | collaborators | 标准可能局部提及，完整协作关系仍需岗位资料 |
| 须补实证2 | entry_for_fresh | 企业招聘学历/专业/无经验条件仍需JD计数，不能用考核报名条件替代 |
| 须补实证3 | metrics | 技术质量要求可参考；企业绩效指标及权重需另证 |
| 须补实证4 | growth | 能力等级可以展示；升职路径、速度和岗位转移需另证 |
| 须补实证5 | risks / misconceptions | 安全规范可供核验；个人体验、常见误解不能从标准臆造 |
| 产品整理1 | questions | 根据官方要求与证据缺口生成建议问题 |
| 产品整理2 | search_keywords | 官方名是线索；平台真实关键词主要由招聘标题产生 |

另设技能关系表保存：职业代码、标准版本、方向、等级、工作功能、工作内容、能力、知识、页码与来源。不要把标准的五级/三级直接接成公司职级，也不要把标准里的考核权重接成任务重要度调查或工时比例。以上为设计建议，未改运行时或职业树。

## 5. 复用许可与建议

已确认公开读取部分官方正文与PDF；尚未确认全量开放下载、商业再分发授权、统一API及跨职业技能唯一标识。公开查询、技术可抓、许可可用必须分开记录。

《著作权法》第五条排除特定具有立法、行政、司法性质的文件等；不能因此推断所有政府网站PDF、出版物版式、培训教材和第三方数据库均可商用复制。当前适宜提取核验后的事实字段、独立整理表达、保存版本和引用；整库镜像或出版发行需逐项核清授权，本报告未给出已获许可结论。[国家版权局现行法条](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)

建议采用：中国官方资料定本土职业边界和规范能力 → ESCO补通用技能关系 → 中国JD定招聘名称和入门条件 → 合格从业长文补工作现实。优先对现有195节点做职业边界核验，保留exact/broader/narrower/none及理由，而不是按名称强行贴编码。然后以相关国家标准抽任务—技能—知识，逐项记录版本与页码。此建议替代之前仅以国际体系为主的暂定方向，但尚未自动改动已存分类和数据契约。
