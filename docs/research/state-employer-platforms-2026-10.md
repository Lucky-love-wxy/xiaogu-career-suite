# 国企、事业单位与编制类招聘来源盘点

访问日期：2026-10-11，Asia/Shanghai。执行范围：公开未登录静态资料、官网目录与声明、现有本地样本；未登录、未注册、未使用用户浏览器会话，未访问 BOSS 或脉脉，未改运行时、职业库或岗位卡，未 commit/push。

公务员以国家公务员局、组织部门公布的考录公告和职位表为准；事业单位以主管人社部门及单位官网具体招聘公告为准；国央企员工以实际招聘企业官网或企业授权发布的招聘信息为准，国资委与综合招聘平台是发现入口，不能替代招聘主体、用工身份和截止状态核验。本轮没有确认可直接启动小谷商业招聘数据库采集的全套许可：一部分声明允许有条件的公开或非商业使用，一部分明确限制复制、汇编或抓取，还有大量规则未找到。现有样本也不是当前官方招聘库，因此现在不能据此对用户说“某岗位目前有 N 家国企/事业单位在招”。下一轮只能在核准来源内，按“截至某日、在已核验来源中、未过报名截止日的公告所对应的独立招聘主体”计算；编制岗位、国央企员工、事业单位编外及未知身份分开，不能宣称全国全量。

## 1. 渠道盘点的边界与方法

按简报顺序执行：先形成渠道类型和入口清单并保留未知项，再核 robots/声明，最后采集官方制度与身份信号、做现有样本分类。初版清单冻结于 `evidence/state-employer-2026-10/inventory-frozen.json`；四川/西藏缺网址项后续补证保存在 `inventory-amendments.json`，保留初版缺口，不边查边删。

清单共689行，包含59个核心/补充候选、128个省区市/兵团分类型入口、502个其他现有来源标签；这些不是689个去重、官网已核验的平台。现有2723份映射记录有516种精确 `source` 标签，全部保留在清单中。原始记录正文位于 `data/careerdb/postings.jsonl`，映射记录位于 `postings_mapped.jsonl`。30份试验仅按ID关联本地两文件，不再联网抓这些记录。

31个省区市及新疆生产建设兵团，每地区列考试、人社、卫健、国资四种入口，共128行。考试入口来自中国人事考试网官方导航，卫健入口来自辽宁卫健官方目录，国资来自国务院国资委官方导航，人社来自上海/湖南官方导航。官方导航只证明入口指向：旧域名、跳转页、具体招聘栏目与现运营主体仍须目标页核验。9个人社候选仍为上海人社的导航中间页；西藏国资只取得政府网部门公开报告，独立招聘门户未找到；四川国资联系页本次404，不能把搜索索引当有效官网正文。均保留在清单。

有限穷举的范围是“10种渠道类别、官方省级目录、现有来源标签”，不是全国每个地市、医院、院系和国企的全部网站。地市/医院/高校/企业数量没有稳定可枚举的招聘网站总表，简报也允许单位官网抽样。本轮明确抽样覆盖医药3家、金融2家、能源2家、通信2家、建工2家；同集团母子公司分别列渠道，不把它们当独立央企集团。地方企业用国资发布渠道和真实淮北国企公告作补充，没有穷举全国地方国企。

高校人事处与高校就业网必须区分：前者招本校员工，后者面向学生转载外部招聘。多数本地来源标签只有学校名称，不能凭名称判断是哪类页面；民办学校也不能自动算事业单位。清单以“高校/院系来源标签，功能待核”保留；丁香人才、高校人才网是商业平台，国聘、NCSS是综合就业平台，都不只发布编制或国企岗位。

取证采用 web-access 的脚本公开HTTP静态层，保存原始响应、正文、链接和请求元数据；中智协议原始HTML仅占位，另用无用户会话的Jina静态提取。国聘协议在原始HTTP、静态网页读取及Jina中仍只有JS占位，当前协议正文未找到，搜索摘要中的2021版不作为当前有效条款。按本轮禁止用户会话的范围，没有升级到日常Chrome CDP。403/429/验证页面停站，不用换身份或浏览器绕过。沙箱首次 `Operation not permitted` 已保留，随后通过整批网络执行权限完成，不当作源站失败。

## 2. 平台清单与规则核验

[完整清单CSV](state-employer-platforms-2026-10.csv)包含所有689行及37个字段：名称、网址、主办候选及核验状态、覆盖、内容、原发判断、样本出现、列表/详情路径、robots原文/状态、声明短引/版本/快照、登录、接口/订阅/下载、规则档、条件、身份、转载链路。[来源表CSV](state-employer-platforms-2026-10-sources.csv)保留URL、标题、发布方、版本/日期、访问日、所支撑结论、快照和失败状态。每条证据中的主办候选不能当作已核法人，`publisher_verified` 单列是否确认。

本轮对162个去重主机核验，另补协议独立主机和两个既有缺项入口；每主机最多一个招聘列表/入口样例和一个招聘详情，未翻公告列表页或批量采公告。省级大多数样例是门户而非具体招聘列表，故CSV明确“具体栏目/详情未取样”，不拿首页成功代替公告可读。单位官网选取规则是：五行业企业类别覆盖；高校取人事与就业两种功能；医院取现有来源中样本较多的北医三院及胸科医院；不据这些少量样例外推全部单位。

三档采用保守的当前可用判断。“有条件”只指已读声明中有适用条件，并不代表小谷商业采集已经获批；“不可用”包括明确限制、技术阻断以及规则证据不全，后一种表示暂不接入，不表示已证明法律禁止。CSV的 `rule_fact`、`robots_status`、`condition` 保留三者区别。没有来源被认定为“已获得商业数据库抓取/再分发许可”。9行“有条件”有实际robots请求快照及逐字声明引用，其余680行包含大量原站未核的来源标签，不能用这个比例评价全国网站政策。

robots的404、超时、HTML错误页均记“未找到有效规则”，不是“允许”。例如NCSS和中国银行返回HTTP200的robots内容实际是错误页；国聘的robots明确放行却缺当前协议正文；中国中铁robots放行但版权声明限制内容使用。不同主机不共享robots；`agreement.gaoxiaojob.com`与主站分开核，牛企规则不转移给 `source` 标签所指原站。解析路径支持通配符和允许/禁止的最长匹配，带查询参数的路径单独保留。

## 3. 编制与企业员工的区分规则

公务员法第二条要求依法履行公职、纳入国家行政编制并由国家财政负担工资福利；第112条的参公需满足法定职能及批准条件，不能把所有事业单位叫参公。事业单位人事管理条例包含公开招聘与聘用合同制度；事业编人员签聘用合同不意味着没有编制。劳动合同法针对劳动关系，国有企业员工通常属于企业劳动用工路径；本轮包头市属国企办法明写企业和员工签劳动合同，这是地方制度样例，不外推全国特殊机构或所有用工形式。法条所读版本与公告日期见快照，访问日期不等于法规公布日期。

## 5. 转载链路与去重

官方公告或企业原发 → 主管部门/就业平台 → 高校就业网 → 聚合站，是待逐公告核验的一般链路模型。已确认本地这30条实际取证URL均在牛企直聘，`source` 是转载来源标签，不能证明每一条真正经历了整条链。高校人才网声明部分信息来源于网络、版权归原作者，进一步说明转载不能算独立证据。条款权限也不会沿转载链自动传递。

下一轮应分别保存公告和岗位两种粒度。公告去重键优先原发布方+原公告编号/规范URL；没有编号时，用原发布单位、招聘年度/批次、标题、发布日期、报名截止时间及规范正文哈希做候选归并，并保留人工冲突复核。岗位键为公告ID+实际招聘主体+岗位代码，不能仅按职位名去重。实际签约主体、派遣公司与工作单位分开；同集团子公司分别计独立法人与是否集团归并，两种数量不能混写。

同一公告的转载时间不是原发时间；增补、更正、延长报名和撤销公告需版本关联，不能另计一家。医院同科多岗位不是多家单位，母公司替子公司招人不能只计发布账号；多个平台同一主体不能重复计。没有原公告ID、实际用人单位、职位表行或截止日期的记录进入待核集，不能硬凑N。
