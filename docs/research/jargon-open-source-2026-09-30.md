## 产品决策

1. 将薪酬、休假、团建和补贴表达整理为可检索词条，回答时拆成「原文承诺、仍缺的金额或规则、可能的兑现风险、可直接问的问题、合格回答」。
2. 对具体公司，只有拿到注明日期和团队的 JD、offer、合同或可核验的公司材料时，才说「该公司提供」。匿名分享只能作为核实线索。
3. 薪资一律区分固定现金、条件奖金、股权和非现金福利；没有发放规则不计算成保证年包。
4. 假期一律核实天数、资格、请假审批和是否能实际休；团建核实频次、是否占用休息日、费用和是否自愿。

## 后续调研入口

若要扩展到更多行业，应按岗位场景搜集原始 JD 和实际 offer，再逐条筛选。不能把 GitHub 全量搜索结果或仓库 star 数当作现实待遇数据库。
