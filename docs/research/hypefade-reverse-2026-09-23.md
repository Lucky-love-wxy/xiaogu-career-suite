## 能确认的前端行为

- 页面是 React 单页应用。
- 前端脚本中嵌入约 281 个词条，每个词条包含 `word`、`level1`、`level2`、`level3`。
- 识别时按词长从长到短排序，再对 JD 做精确子串扫描，避免短词抢先覆盖长句。
- 页面把命中词高亮，支持悬停查看和点击展开。
- 三档解释依次接近“字面解释、调侃式翻译、深层拆解”。
- 2026-09-22 的样例运行没有观察到翻译接口请求，也没有发现保存结果的 localStorage；当前可见翻译能力主要在浏览器本地完成。

这些事实不能证明网站全部服务都没有后端，也不能证明前端业务文案具有开放许可证。脚本里的 React MIT 和图标库 ISC 声明只覆盖对应依赖，不能自动延伸到 HypeFade 自己的词典与文案。

## 对小谷的取舍

保留：

- 在 JD 原文中定位黑话。
- 长词优先，减少错误切词。
- 递进解释，先看字面，再看风险。

不复制：

- HypeFade 的 281 条词典正文。
- 三级解释原文。
- 页面代码、样式和交互素材。

改造成：

- 字面意思。
- 露骨翻译。
- 最坏但仍需核实的情况。
- 可以真实观察的危险信号。
- 能直接问招聘方的问题。
- 什么回答算具体，什么回答仍在回避。

这样既能把话说透，也不会把调侃或最坏情况冒充成某家公司的事实。
