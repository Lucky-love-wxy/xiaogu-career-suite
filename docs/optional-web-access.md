# 可选依赖：web-access

`web-access` 提供联网能力。小谷理解岗位时会默认尝试牛客、脉脉等公开从业者说法，有联网工具就用，没有就跳过；它不是小谷本地检索的必需依赖。

- 上游项目：https://github.com/eze-is/web-access
- 是否可用取决于目标 Agent 平台是否提供对应联网或浏览器工具。
- 安装 Skill 不会自动提供任何网站账号、Cookie、登录态或访问许可。
- 脉脉：单帖公开详情页对部分 AI 抓取身份开放（以 robots.txt 为准，2026-10-03 实测对 ChatGPT-User 等开放、对 Claude 禁止）；社区首页与站内搜索需要登录，小谷不访问。
- 牛客：robots.txt 只禁站内搜索等少数路径；内容页可读性待调研确认。
- 访问失败时不阻塞岗位分析；用户明确指定某个社区却读不到时，请用户提供具体链接、截图、合法导出或复制文本。

本项目不复制或内嵌第三方 Skill。用户应从其维护来源安装，以便获得正确版本和依赖说明。
