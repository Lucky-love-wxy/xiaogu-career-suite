# 可选依赖：web-access

`web-access` 用于用户明确要求的网页和职场社区调研，不是小谷核心离线检索的必需依赖。

- 上游项目：https://github.com/eze-is/web-access
- 是否可用取决于目标 Agent 平台是否提供对应联网或浏览器工具。
- 安装 Skill 不会自动提供任何网站账号、Cookie、登录态或访问许可。
- 读取脉脉社区内容通常需要用户自己的登录状态；公开首页可读取不代表社区帖子可读取。
- 访问失败后应直接报告失败步骤和错误，并给用户一个可行方案：提供具体链接、截图、合法导出或复制文本。

本项目不复制或内嵌第三方 Skill。用户应从其维护来源安装，以便获得正确版本和依赖说明。
