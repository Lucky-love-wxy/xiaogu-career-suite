- 样本：campus_sample.jsonl（校招 50 份，从牛企直聘已抓单岗页按大类轮流随机抽，每家公司最多 1 份）；social_draws.md（社招 50 份抽签单，用户照单取 JD）。随机种子 20261012，`python3 scripts/jargon_eval/sample.py` 可复现。
- 每部分对半分：tune（可以据此补词条和同义写法）、holdout（只用来算覆盖率，不许据此改库，否则覆盖率会虚高）。

## 什么算“黑话”（标注口径）

算：招聘方写得模糊、需要追问才知道实际含义的招聘话术，分四类——
1. 工作方式与强度：弹性工作、节奏快、抗压、可接受出差/加班
2. 能力与态度要求：Owner 意识、执行力强、学习能力强、结果导向、跨团队推动
3. 待遇与福利：14 薪、综合薪资、年包、五险一金按 Base 缴纳
4. 公司与团队状态：快速发展期、从 0 到 1、孵化产品、扁平化、年轻团队

不算：行业业务术语（曝光、转化、客户消耗、RAG、GCP）——另记一列“业务术语”，单独统计，不进黑话覆盖率。

## 标注流程

1. 先标后跑：标注时不看小谷的匹配结果，逐份标出原文里的黑话片段（必须是原文一字不差的片段），并标所属类别。
2. 再跑匹配器，每处黑话归入：直接命中 / 同义写法命中 / 库里有意思相同词条但没匹配上 / 库里真没有。
3. 双人一致性：Claude 和用户各自独立标同一批 10 份，对不上的地方讨论后修订口径，再标剩下的。
4. 统计：holdout 上按出现次数算覆盖率（目标 ≥ 90%）；每 20 份统计一次新增黑话数，连续两批 < 2 视为常见黑话已收齐。
